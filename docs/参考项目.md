与本地克隆 `git remote get-url origin`（Biz Novel Studio），不是凭记忆。

| 仓库内位置 | `packages/bundle`（分支 `v8`） |
| npm 包 | `@linfengqaqtat/dsh-scriptor` 8.2.0 |

## 三家分工（写作时的取用方式）

- **Biz** 偏角色向：这类人物怎么推动情节
- **Scriptor** 偏机制向：这个桥段为什么有效
- **oh-story** 偏结构向：章节 / 卷怎么排

三种都要，且拆出的每条机制都要标明属于哪一类。
